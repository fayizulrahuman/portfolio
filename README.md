## ✨ Overview

Welcome to my personal portfolio! This website is designed to be more than a traditional portfolio — it offers an interactive, visually immersive experience with creative 3D-inspired elements, smooth navigation, and engaging animations.

It highlights my work, technical interests, and development journey.

## 🚀 Features

- **Immersive Hero Section** – Unique visual introduction with oversized typography and interactive elements.
- **3D-Inspired Experience** – Interactive visual elements and immersive laptop-themed presentation.
- **About Me** – Personal introduction and professional interests.
- **Projects Showcase** – A collection of selected development projects.
- **Technical Skills** – Technologies, programming languages, and tools.
- **Contact Section** – Connect with me for opportunities and collaborations.
- **Responsive Design** – Optimized for different screen sizes.
- **Smooth Navigation** – Seamless browsing experience.

## ⚙️ Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/fayizulrahuman/portfolio.git
```

### 2. Navigate to the project

```bash
cd portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Create a production build

```bash
npm run build
```

The production-ready files will be generated inside the `dist/` directory.

## 🌍 Deployment

This portfolio is deployed using **Vercel**, with GitHub integration for automatic deployments.

Every new push to the `main` branch can trigger a new deployment.
